# 🚀 50 Days of DSA Challenge

Welcome to my **50 Days of DSA Challenge**, where I solve two Data Structures and Algorithms problems every day as part of the **Dr. G. Viswanathan Challenge**.

The goal is to build consistency, strengthen problem-solving skills, and improve my understanding of DSA through regular practice using **Java**.

## 🎯 Challenge Goals

* Solve 2 LeetCode problems every day.
* Strengthen DSA concepts through practical implementation.
* Improve logical thinking and problem-solving skills.
* Maintain consistency and track daily progress.
* Document my learning journey on GitHub and LinkedIn.

* **Language:** Java

* **Challenge:** Dr. G. Viswanathan Challenge
